# vai

*vai* (Portuguese: "go!") is a programming language with Ruby/Elixir-flavoured syntax that lowers to idiomatic Rust, keeping Rust's semantics — ownership, borrowing, zero-cost abstractions, fearless concurrency — and seamless two-way interop with the crates.io ecosystem.

Status: design phase. The way to a v0 spec is being charted as a wayfinder map in this repo's issues.
